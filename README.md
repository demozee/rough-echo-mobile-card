# ROUGH ECHO / SOFT BLOOM

A responsive, two-sided interactive art card built with Three.js.

- Tap to flip; drag to tilt and flip at the threshold.
- Mouse and device-orientation input.
- Layered artwork parallax, rising embers and falling snow.
- No login, build step, external CDN or backend required.

## Preview

Run `python3 -m http.server 8000` in this directory, then open
`http://localhost:8000`. Motion sensors require HTTPS on mobile and may
require a user gesture before the browser shows its permission prompt.

## GitHub Pages

In repository Settings > Pages, publish the `main` branch from `/ (root)`.
All asset URLs are relative and work under a repository subpath.
